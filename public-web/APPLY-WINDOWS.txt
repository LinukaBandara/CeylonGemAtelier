WHY IMAGES WERE BLANK
---------------------
The site looks for files under public-web/public/images/...
If those files are missing on your PC, you get empty beige boxes.
Craft steps 2-4 showed because only those files were present.

WHAT THIS FIXES
---------------
1. All homepage images included
2. 2. Cutting  = new blue sapphire on the wheel (water spray)
3. 4. Documentation = new GIA report with blue sapphire
4. GemImage no longer leaves empty boxes (shows gem shape until photo loads)

APPLY (PowerShell)
------------------
1. Download cga-images-fix.tar.gz
2. Open folder where you cloned the repo (must contain a public-web folder)

   cd C:\Users\linuk\CeylonGemAtelier

3. Extract the archive INTO the repo folder, then merge:

   tar -xzf $env:USERPROFILE\Downloads\cga-images-fix.tar.gz
   Copy-Item -Path .\public-web\* -Destination .\public-web\ -Recurse -Force

4. Confirm files exist:

   dir public-web\public\images\home
   dir public-web\public\images\craft

   You should see hero-sapphire.jpg, featured-rough.jpg, cutting.jpg, documentation.jpg

5. Restart the dev server:

   cd public-web
   npm run dev

6. Hard-refresh the browser (Ctrl+Shift+R)

If still blank, the image path is wrong — tell me the output of:
   dir public-web\public\images\home
